entah kenapa kalau dapat europe-west1 us-west1 error jadi harus stop lab, ganti lab baru untuk mendapatkan europe-west1 lain.

langkah-langkah

1. aktivasi api

```
gcloud services enable \
  artifactregistry.googleapis.com \
  cloudfunctions.googleapis.com \
  cloudbuild.googleapis.com \
  eventarc.googleapis.com \
  run.googleapis.com \
  logging.googleapis.com \
  pubsub.googleapis.com
```

2. buat task 1 cloud storage bucket

```
gsutil mb -l europe-west1 gs://qwiklabs-gcp-01-03fe0eb5cf1b
```

ganti europe-west1 dan qwiklabs-gcp-01-03fe0eb5cf1b dengan data lab
copy hasil alamat bucketnya dengan awalan gs://

3. grant the pubsub.publisher IAM role to the Cloud Storage service account

```
# 1. Get the current Project ID from your active configuration
MY_PROJECT=$(gcloud config get-value project)

# 2. Get the Project Number
PROJECT_NUMBER=$(gcloud projects list --filter="qwiklabs-gcp-01-03fe0eb5cf1b:$MY_PROJECT" --format='value(project_number)')

# 3. Get the GCS Service Agent email
SERVICE_ACCOUNT=$(gsutil kms serviceaccount -p $PROJECT_NUMBER)

# 4. Bind the role
gcloud projects add-iam-policy-binding $MY_PROJECT \
  --member serviceAccount:$SERVICE_ACCOUNT \
  --role roles/pubsub.publisher
```

4. buat file index.js dan package.json

```
mkdir ~/hello-storage && cd $_
touch index.js && touch package.json
```

buka file editor masukan data index.js dan package.json yang ditetapkan oleh lab
terutama index.js kata eventStorage diganti dengan yang di lab (misal di lab cs-monitor)

5. buat cloud storage function

```
gcloud functions deploy namafunction \
  --gen2 \
  --runtime nodejs20 \
  --entry-point namafunction \
  --source . \
  --europe-west1 europe-west1 \
  --trigger-bucket bucket \
  --trigger-location europe-west1 \
  --max-instances 2
```

jika muncul error eventarc, jalankan ulang commandnya.

ganti namafunction, bucket, europe-west1 dengan di data lab.

task 3 bisa lihat lab Cloud Run Functions: Qwik Start quick start task 2
