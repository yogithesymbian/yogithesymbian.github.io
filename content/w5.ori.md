Here are the steps to deploy the Billing Service as an unauthenticated Cloud Run service using Cloud Build:

Open Cloud Shell:
Go to the Google Cloud Console and activate Cloud Shell.
Clone the Repository:
git clone https://github.com/GoogleCloudPlatform/pet-theory.git
cd pet-theory/lab07/unit-api-billing

Replace PROJECT_ID with your Google Cloud Project ID ( qwiklabs-gcp-02-385e41d5509e ).
gcloud builds submit --tag gcr.io/PROJECT_ID/billing-staging-api:0.1
Generated code may be subject to license restrictions not shown here. Use code with care. Learn more

Deploy the Cloud Run Service:
Replace PROJECT_ID with your Google Cloud Project ID ( qwiklabs-gcp-02-385e41d5509e ).
Choose a region for your Cloud Run service (e.g., us-central1 ).
gcloud run deploy public-billing-service-419 \
 --image gcr.io/PROJECT_ID/billing-staging-api:0.1 \
 --platform managed \
 --region us-central1 \
 --allow-unauthenticated \
 --project PROJECT_ID
