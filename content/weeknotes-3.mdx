# english

to set ai token pricing plan for your app:

- define how many tokens each plan includes per month/week
- set max tokens per request to limit usage
- decide extra usage fee or top-up option
- match token allocation with expected api cost per user
- optionally create tiers for light, medium, heavy users

# indonesia

cara atur ai token pricing plan untuk aplikasi:

- tentukan berapa token tiap plan per bulan/minggu
- atur max token per request untuk batasi penggunaan
- putuskan biaya ekstra atau opsi top-up
- sesuaikan alokasi token dengan perkiraan biaya api per user
- bisa buat tier untuk user ringan, sedang, dan berat
